# dsh-GOkifu-compact 1.19.0 发布说明

> 发布日 2026-11-09。上一版 1.18.5。
> 本版的**唯一主题是内存**：插件过去把每个会话的棋谱图按会话永久常驻、**没有任何清理路径**，

## 一、内存：把「关掉的会话」真正还回来

### 问题

`graphs` / `runtime` 两个缓存按会话常驻，**从来没有清理路径**。窗口关了、会话归档了，图还在进程里。
本机实测（1592 张真实 `graph.json`、222.4 MiB、17.7 万节点 / 24.9 万边）：

| 口径 | 全部驻留 | 回收后 |
|---|---|---|
| 堆 | **+295.7 MB** | **+0.3 MB** |
| RSS | **+418.1 MB** | **67.4 MB（第 8 秒回到基线）** |

### 做法

**唯一一道闸门**（不是「到点就删」的定时器）：只有下面六条全绿，才把 `runtime` 与 `graph`
**成对**释放 —— 单删任一半会让下一次事件拿「新图 + 旧运行态」，比泄漏更糟。

1. 没有 pin（折叠 / 手动压缩 / 收尾 / 离线补折正在进行时，图被钉住）；
2. 没有待写的 debounce timer；
3. 会话不活跃（宿主报 `running` 过的除外）；
4. **静默窗口**：最近一次有动静（事件 / 状态 / 被 pin）距今 ≥ 15 分钟；
5. 有过一次**成功的 full 落盘**，且此后没有失败；
6. 图不脏（没有未落盘的改动）。

**保留失败图**：落盘失败 / 脏图 / 折叠退避中的图一律不回收 —— 内存是那一刻唯一的副本。

回收时机：`agent/status: idle` 的回合边界扫一遍别的会话（保留当前热图）；会话被销毁或归档时，
在 closeout **最终 flush 之后**回收。

### 三条风险补丁（本版新增）

- **活跃性不只认 `agent/status`**：`session/event` 与被 pin 都算「有动静」，再加 15 分钟静默兜底 ——
  兜住离线补折、脚本/无头调用这类不一定发状态的路径。
- **fold 之后不许马上回收**：折叠成功会改一批只在 full 落盘时写出的标量（`lastFoldSeq` / `foldCount` /
  `foldThrash` / foldMarks…）。现在 fold 成功即作废 `full` 标记，必须等到下一次成功 full 落盘才放行。
- **`sessionRefs` 一并释放**：只删图不删 Session 引用，「回收了但内存不降」就还在。同时用一张封顶
  4096 的 `seenIds`（只存 id 字符串）保住「本进程处理过这个会话」这条判据，**归档收尾不会被静默跳过**。

### 代价与边界

- 冷图被回收后，**下一次事件要重读磁盘**。这是回收的代价，由「静默 15 分钟 + 保留当前热图」压住。
- **磁盘零变化**：回收路径只有 `Map.delete`；实测 1592 张图的 mtime 逐个未变。
- 这是资源生命周期，**不是可关的特性**：它不需要开关，出问题该调的是静默窗口。

## 二、可复现性：干净 checkout 上全量测试现在真的绿

K-2 的 AX-03 冻结产物（预注册 / 夹具 / 哈希清单）原来只在 git 忽略的 `tmp/` 里。后果是
**新克隆上全量测试跑不绿**：`K2-13` 直接 `ENOENT` 判红，`K2H` 整组 `skip` —— 门禁形同虚设。

现在三个文件按**原始字节**版本化到 `test/fixtures/ax03/`（`.gitattributes -text` 关掉 EOL 转换，
因为 `FROZEN_BASELINE` 里的 `rawBytesSha256` 就是按字节算的）。干净 checkout 上 `k2` **80/80 全绿**。

## 三、研究线（不改变默认行为）

K-27 关系行**渲染消歧 v4**：把状态从 `status=<词>` 的值位改成方括号标签 `[<词>]`。
理由是真机 reader 在「最新结算状态是什么」这类题上会把**状态词的值**当答案（v3 三个样本全答 `settled`，
金标准是 `later-ok`）；改形态后同一题三个样本全对。

同窗配对对照（v1 vs v4，120 次调用、0 重试、0 错误）：两臂 compact 多数票都是 **10/10**、
样本级 29/30 → **30/30**、逐题**零翻转**。结论是「**消歧这一刀有效**」，但 **10 题 pilot 已饱和** ——
**不能据此说「关系行更好」**。

formal 50/50 仍 **NOT_RUN**，裁决仍 **NOT_ADOPTED**，关系行渲染仍**不默认开启**。

## 五、升级 / 回滚

```bash
dsh plugin --profile desktop add dsh-gokifu-compact@1.19.0
# 回滚
dsh plugin --profile desktop add dsh-gokifu-compact@1.18.5
```

升级后由使用者在方便时**重启 DSH**，再检查：

1. `npx dsh-gokifu-compact doctor` 的运行版本为 **1.19.0**；
2. 跑几个会话、关掉其中几个，再看内存：冷掉的会话的图不该一直占着；
3. 需要观察时跑 `node scripts/graph-cache-memory.mjs --top 12`（只读，不写 home）。
