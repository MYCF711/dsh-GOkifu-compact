# 发布说明 · 1.18.0（2026-11-06）

> 中版本从 **1.17.6** 推进到 **1.18.0**，小版本号归零。
> 本版重点：无头补折真正使用上下文压缩设置里的模型；手动折账不再跨会话串区间；面板按主次分层并调整补折卡位置。

## 一、压缩记账与保真

| 编号 | 用户可感知的变化 |
|---|---|
| C653 | 模型把约束只改了空白排版时，最终摘要会恢复为棋谱里的逐字原文；完全缺失才追加，不再重复补段 |
| C654 | 即使会话只剩历史残留失败，热清单也保留残留计数与 `graph.json` 指针，不再显示成“没有失败账” |
| C655 | 手动 `/compact` 的区间与遮蔽 token 只认本次宿主返回，杜绝另一会话的 pressure fold 覆盖本次账目 |
| C652 | doctor 导入失败会真实返回失败，不再把「检查没跑起来」显示成 0 错误 |

C655 的原始跨会话复现已从错误的 `9406–10630 / openAtEnd=1` 修为真实的 `47944–53347 / openAtEnd=0`。代码只阻止新错误，不会擅自改写既有 foldMark。

## 二、无头补折与模型选择

- 补折按钮派**无头子代理**，不弹出工作会话；使用上下文压缩设置里的默认 provider/model 直连摘要，并核验结果真实落盘。
- 面板提供 provider 与模型选择；请求会显式携带 `summarizationProvider` / `summarizationModel`。
- 自动压缩阈值只提供固定档位，不开放任意数字。
- 跨会话折痕缓存按实际工作集分配，避免第二次加载重复读盘。

## 三、面板层级与顺序

- 总览按主信息与诊断信息分层，次要内容可折叠，不再把所有指标一次铺开。
- **补折卡移到「最近活跃会话 / 检查更新」上方**。这是既有节点顺序调整，组件、样式、事件、模型选择器、按钮文案与空态均未改。

## 四、验证与已知边界

- 全量：**2072 passed / 0 skipped / 0 failed**；boundary-audit **0 条**；verify-install **全部通过**。
- live handoff 的残留失败项已转绿；仍保留两条**历史 foldMark** FAIL（旧约束 recall=0、旧错误区间），没有通过改写 live 图或放宽判据来制造全绿。
- 未重启、未安装、未调用真模型；生产加载与真实 GUI 像素仍需在测试实例验收。

## 五、升级 / 回滚

```bash
dsh plugin --profile desktop add dsh-gokifu-compact@1.18.0
# 回滚
dsh plugin --profile desktop add dsh-gokifu-compact@1.17.6
```

升级后由使用者在方便时重启 DSH，再检查：

1. `npx dsh-gokifu-compact doctor` 的运行版本为 **1.18.0**；
2. 面板中补折卡位于最近活跃会话与检查更新之前；
3. 选择一次无头补折后，核对实际摘要与 `foldMark` 落盘，而不是只看按钮提示。
