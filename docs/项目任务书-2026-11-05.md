## 一、这是什么

DSH 的**上下文压缩后端**：把长会话压成「棋谱（graph）」—— 节点是状态步、边是尝试、死路/事实/约束是显式字段，
而不是一段自然语言摘要。它同时提供三件事：

1. **在线折叠**（`compactRegion` / `compactIfNeeded`）：会话跑长时按压力阈值压缩；
2. **归档收尾 + 离线补折**：会话归档后仍有尾巴，用**默认模型**读日志补压（无头，不弹会话）；
3. **账本与观测**：foldMark（每段可审计）、成本/命中率/保真度、doctor 健康检查、面板设置。

规模：`src/rooms/*.mjs` 24 个模块 · `scripts/*.mjs` 61 个 · 测试 **1373 passed / 0 failed**（148 文件 / 1054 用例）。

---

## 二、优点（有证据的）

| 优点 | 证据 |
|---|---|
| **每段折叠可审计** | foldMark 记 `seq 区间 / 摘要字符 / 耗时 / usage / 质量`；`verify-archive` 一条命令给出全库判决 |
| **不会"假成功"** | `folded>0` 必须同时有证据（mark 或 `chunkedFolded`），否则判欠账（C569/C572） |
| **无头** | 离线补折不传真实 sessionId，不弹会话（C525） |
| **缓存友好** | 真机命中 **94.2%**（跨轮共享"提示词+硬事实"前缀） |
| **失败可定位** | 新增 `auto-backfill-state.json` + `backfill-state.mjs`：挑中谁、结局、错误原文 |
| **门禁自成体系** | 6/6 判分门 + boundary-audit 0 条 + 148 文件 1054 用例 |
| **不依赖外部服务** | 全部逻辑在本地；模型只走宿主 `ctx.llm`（可换 provider） |

## 三、特点（设计取向）

1. **棋谱优先于摘要**：摘要只是渲染结果，事实在图上；所以能回答"这一步得出了什么"。
2. **一条规则只写一次**：判据抽成纯函数（`debtOfGraph` / `closeoutSettles` / `foldBudgetFor`），两条路径共用，避免"只改一条"。
3. **守卫必须能证伪**：每条修复都配一条"会在什么时候红"的用例；探测器自身也要被测试（今天抓到 3 个恒真/恒假的探测器）。
4. **诚实边界**：做不到的写进文档，而不是假装支持（见 §五）。

## 五、后续目标（按优先级，可并行）

### P0 · 让补账真正追平（D1/D2）
- **目标**：欠账从 218 降到 **< 50**，且「24h 折段数」> 「24h 新增欠账」。
- **方案**：
  - 按段耗时自适应 `maxChunks`；对超大会话先用更小预算粗压（4096）；
  - 慢模型下把「每段」拆成"先压骨架、再补细节"两档；
  - 出 `backfill-forecast.mjs`：给定参数算出追平小时数（**先算再做**）。
- **验收**：`node scripts/backfill-forecast.mjs` 显示追平 < 24h；`status` 的欠账数连续两轮下降。

### P1 · 消灭"静默停摆"剩余面（D3/D5）
- **目标**：任何后台 job 停止时，**一条命令**能说出原因。
- **方案**：`fold-timeline.mjs`（时间线）+ doctor 三条新检查（状态文件过期/结局异常/从未跑过）。
- **验收**：人为让 job 失败一次，doctor 必须给出**具体**原因，而不是"未采集"。

### P2 · 补齐真机证据（D4/D7）
- **目标**：分段折叠与并发折叠各有一条**真机/受控**证据。
- **方案**：构造一个 >`closeoutMaxFoldTokens` 的会话跑分段；并发用两个引擎实例争同一 graph 做对照。
- **验收**：文档里能贴出 `chunkedFolded>1` 的真实 foldMark，且并发下无"空转/重复折"。

### P3 · 文档与守卫同源（D6）
- **目标**：文档里的数字**只能来自脚本**，不许手写。
- **方案**：`test-counts` 单一来源 + 文档模板占位符；守卫只校验"来源存在"，不校验具体数值。
- **验收**：改一个数字不用改文档，跑一次 `--write` 全绿。
