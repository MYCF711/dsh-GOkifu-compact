# 发布说明 · 1.18.1（2026-11-06）

> 在脱敏稳定版 **1.18.0** 上仅追加一项判级修复（T90）。基线已包含至 **C655** 的改动；本版不改折叠算法、不清空历史计数，也不携带本地 beta 历史。

## 输入裁切不再误报为当前压缩出错

旧面板把 `inputTruncated > 0` 与「摘要输出截断」合并为红色「出错」。实际健康检查中，插件已安装、已接管、单后端，输出截断为 0，仍会因为历史输入裁切计数而误报。

现在：

- **只有输入裁切**：状态为「正常」，继续显示 `输入裁切 N`；
- **历史截断状态未知**：状态为「正常」，继续显示 `截断状态未知 N · 未知不等于未截断`；
- **输出截断、host/state 读取错误、多后端**：仍然显示「出错」；
- 两项观测计数都保留，**没有清零或隐藏**。

真机形态 `truncated=0 / inputTruncated=213 / truncatedUnknown=7` 的真实 React host 卡已验证为 `data-status-kind=normal`。
