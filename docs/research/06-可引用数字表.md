## 六、引用纪律

1. **标来源**：`[外]` 的数字不要说成我们的；`[本]` 的数字要说明**哪天的实测**（`evidence/README.md` 有新鲜度分档）。
2. **别跨口径比较**：夹具口径（417 tokens，C122 更正；旧 446）与真实分词（594 prompt tokens）不是一回事。
3. **数字会变**：模型版本、夹具、采样数都会让数字漂移（8/8 → 6.67/8 就是例子）。引用时带上时间。
4. **宁缺毋滥**：本表只收"会被引用"的数字；一次性观察留在各调研文档里。
