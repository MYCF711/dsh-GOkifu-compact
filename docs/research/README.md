# `docs/research/` 索引：调研与蒸馏的唯一入口

> 这里放「持续调研」的产出：外部证据（学术 / 产品 / 认知 / 记忆系统 / AGI 架构 / 触发与预算），
> 以及把它们收敛成「只做压缩本职」的可执行结论（`00`）。
>
> **阅读顺序**：先 `00`（唯一收敛点，含候选清单与不采纳清单）→ 需要证据时再按主题翻 `01–07`。
> **维护规则**：新增调研文件必须登记到本文件；`node scripts/docs-index-check.mjs` 会检查（未登记 = exit 1）。
