# docs 索引

> 本目录是**设计/契约/证据**的落点。`docs/research/`（调研·蒸馏）与 `evidence/`（实测数据）各有自己的索引，
> 这里只收本层文件。`scripts/docs-index-check.mjs` 会检查「本层每个 .md 都在这页出现」。
>
> 判读顺序建议：**职责边界 → 重注入契约 → 落盘与回滚不变量 → 发布就绪**（这四份是会被人照着做的），
> 其余按需查。
