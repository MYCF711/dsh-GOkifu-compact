## 1. 它主张的三件事（**待核实**：我们只读了摘要，没读正文）

1. Agent 的**自演化能力**建立在**记忆**上 —— 没有记忆就没有跨回合的自我修正；
2. 记忆设计**散落在各篇论文里**，缺少统一的设计模式归纳（这正是它要补的缺口）；
3. 它按「是什么 / 为什么 / 怎么设计 / 怎么评测 / 有哪些应用 / 局限与未来」组织 ——
   **「怎么评测」被单列成一节**。

## 2. 对我们最有用的那一条：**评测被单列**

我们的记忆层（棋谱）一直有个弱点：**质量指标都是自己定的**（`constraintRecall` / `failureRecall` /
`compressionRatio`），没有和外部评测口径对齐过。这份综述把「记忆模块怎么评测」当成独立问题，
说明这件事**不是我们自娱自乐**——
⇒ 候选（不新开编号，并入 K-6 的验收）：下次动质量指标时，先对照「记忆评测」的常见维度
（**保真 / 可寻址 / 时效 / 抗干扰**），我们现在有前三项，**抗干扰（干扰项）一项没有指标**。

## 3. 与现有认知的一致性

- 与 Anthropic《context engineering》一致：记忆的价值在**跨回合**，不在单次上下文里；
- 与 LangChain 四类策略一致：我们占 write/select/compress 三格，本综述说的「记忆模块」大致对应 write+select；
- 与 Chroma context rot 一致：**干扰项会拉低准确率** —— 这正好是上面缺的那一项的出处。

## 4. 一句话蒸馏

> 「记忆」这件事已经被系统化了，**评测是其中独立的一环**。
> 我们的三个质量指标覆盖了保真与可寻址，**缺「抗干扰」**——这是 K-6 唯一还没指标化的维度。
