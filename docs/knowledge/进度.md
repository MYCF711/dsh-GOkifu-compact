## 第 42 轮 · 2026-11-02 23:4x（goal 第 40 轮）· 补账失败要**点名**

**问题（读客户端代码发现的）**：补账真跑失败时，面板只显示一行

```
补完 9 / 12（真折叠 9；失败 3）
```

—— **哪 3 个失败、为什么失败，一概不知道**。而 `backfillArchivedSessions` 明明把 per-item 的
`{ sessionId, ok, error }` 都返回了（`results`），只是没渲染出来。12 个会话补账时出现"失败 3"，
用户只能一个个猜。

**做了（C258）**：`backfillLines()` 在真跑且有失败时，把**最多 5 条**失败逐条点名：

```
补完 9 / 12（真折叠 9；失败 3）
✗ session-bbb-222 · resume 没有拿到 live agent
✗ session-ccc-333 · timeout
…另有 1 个失败
```

`skipped: "dry-run"` 的条目**不算失败**（那是 dryRun 模式的正常标记），不许混进来。

**测试**：`ui-update` 的 C234 用例扩了三断言 —— 行数、点名、原因；外加一条反向断言
（skipped 的会话 id 不许出现在列表里）。
