# 落盘与回滚的不变量（2026-11-02，C110–C114 收口）

> 为什么单开一份：C110 → C113 是**同一片区域的四层发现**，每一层单独看都像小问题，
> 叠起来却会变成「重启后既看到旧索引、又丢节点」。这份文档把它们收成一张表，
> 供后人改动落盘/回滚代码时对照，而不必重新踩一遍。

## 三份产物，一个真相源

| 文件 | 作用 | 谁读它 |
|---|---|---|
| `graph.json`（+ `delta.jsonl` 回放） | **唯一真相** | 引擎、doctor、交接检查 |
| `index.md` | 人读的索引（全量渲染） | 人、模型（`TRACE` 指向它） |
| `nodes/<id>.md` | 单节点详情 | 热清单省略行的指针目标 |

## 不变量（每条都有测试）

| # | 不变量 | 违反后果 | 测试 |
|---|---|---|---|
| 1 | 热清单省略行指向的 `nodes/<id>.md` **必须存在** | 空指针：模型去读 → ENOENT | `node-docs` C110、`doctor-cli` C110 |
| 2 | `nodes/` 里**不该有**图里不存在的 id 的残留（可以有，但不该持续增长） | 只是噪音，不误导 | C110 计数、C111 清理 |
| 3 | `tree` 落盘必须**清掉**「已不在图里」的节点文档 | 残骸永久累积 | `kifu-persist` C111 |
| 4 | **回滚**（恢复快照）后必须走 `tree` 落盘 | `index.md` 停在回滚前 | `fold-mark-sites` C112、`kifu-persist` C112 |
| 5 | **回滚**必须连 **dirty 记账**一起清（`restoreFromSnapshot`） | 失败尝试的 `delNodes` 随下一个 delta 帧落盘 ⇒ 下次 `load` 把已恢复节点再删一遍 | `kifu-model-snapshot` C113-1/2 |
| 6 | 回滚 → 落盘 → `load` 的**端到端**结果必须与回滚后的图一致 | 重启后节点消失 | `kifu-model-snapshot` C114 |

## 允许的、别误判的现象

- **`seqStart/seqEnd` 区间可以重叠**：fold 后 surface 上的 checkpoint 节点带更早 seq，
  下一次 fold 的 `seqStart` 会「回落」。真正的判据是**节点级单调**（`live-folds` 的闭包链 C103）。
- **陈旧 `nodes/*.md` 计数不为 0 不算故障**：它是「写了又回滚」的历史残骸，
  会在该会话**下一次 fold** 时被 C111 清掉；doctor 只计数、不报警。
- **`closure.nodes > graphNodes`** 用的是**折叠当时**的图规模（`closure.graphNodes`），
  之后的合并缩图**不会**误伤历史闭包（C106 / H-17）。

## 出问题时的处置（只增不删）

| 症状 | 命令 | 说明 |
|---|---|---|
| 某些 `nodes/<id>.md` 缺失（热清单省略行会指向它们） | `node scripts/graph-audit.mjs --repair --dry-run` 先看，再去掉 `--dry-run` | **只补写缺失的派生视图**（`renderNodeMd` 的确定性输出），不删不改已有文件；真相仍在 `graph.json` + `delta` |
| 结构不自洽（悬空边 / 索引 / order / 闭包） | `node scripts/graph-audit.mjs` | 只读体检；doctor 里也有同一条（C140） |
| **`index.md` 说存在、图里没有**（C142 那种分裂的表征） | `node scripts/graph-audit.mjs`（C151 检查项） | 索引是派生视图；分裂说明曾经有回滚未同步 |
| 想确认 doctor 的口径是否与运行时一致 | 看 doctor 输入是否经 `loadSessionGraph`（**会重放 delta**） | C143：不重放 delta 的体检会假绿 + 误报陈旧 |

## 改这块代码时的检查清单

1. 动了回滚路径 ⇒ 跑 `kifu-model-snapshot`（C113/C114 会红）；
2. 动了 `tree` 落盘 ⇒ 跑 `kifu-persist`（C111/C112 会红）；
3. 动了节点文档 ⇒ 跑 `node-docs` + `doctor-cli`（C110 会红）；
4. 任何「写了文件但不回收」的新路径 ⇒ 先想清楚它是**真相源**还是**派生视图**；
   派生视图必须能被重建，且重建时机要让 C111 的清理有机会跑到。
