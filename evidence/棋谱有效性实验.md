# 棋谱有效性实验：干净子代理 + 真实破产项目

> 2026-10-28 · 目的：回答「棋谱能不能让一个没有记忆的 agent 规避重蹈覆辙」
> 以及「原始记忆到底要不要保留」

## 实验设计

**素材**：`magpie-today-plugin` 的真实失败记录 —— 从 `HANDOFF.md` + `CHANGELOG.md` 抽出 **15 条已探明死路**（e1–e15），每条都有原文出处。

**棋谱文件夹**（`tmp/chess-experiment-today/`）：

```
index.md          1,939 字符（15 条死路，每条一行「意图 → ✗ 一句话原因」+ 链接）
nodes/e1..e15.md  每条：意图 / 真实结果 / 修法 / 边的记录 / raw 链接
raw/e1..e15.md    原始文档段落
```

**两个隔离子代理**（都不继承主会话记忆、都禁止用 hindsight 工具、都禁止读项目源码）：

| 组 | 给它的资料 |
|---|---|
| **实验组** | 棋谱文件夹（index + nodes + raw） |
| **对照组** | 两份**原始文档全文**：`HANDOFF.md`（8KB）+ `CHANGELOG.md`（3KB） |

**同一个任务**：给 `magpie-today-plugin` 加「webhook 通知」功能，写实施方案。

## 结果

| 判据 | 实验组（棋谱） | 对照组（原始文档） |
|---|---|---|
| 引用死路数 | **15/15** | 5 条（坑 1、3、4、5 + 正文不增量） |
| 方案质量 | 高：文件名/API/重试/单测清单 | 高：outbox/HMAC/断线续订，部分更细 |
| 超出给定资料 | **0 条** | **2 条**（棋谱里没有） |
| 读取量 | index 1.9KB + 15 个节点 ≈ 7KB | 11KB |

### 对照组补出来的两条（棋谱漏了）

1. **长轮询漏 `afterSequence` 直接 400，`waitMs` 上限 25000** —— HANDOFF 16:55 段有，我抽 15 条时漏了
2. **正文不增量**（流式只是形状，首字≈总耗时）—— HANDOFF 速度段有，也漏了

## 结论

### 1. 棋谱确实能规避重蹈覆辙（实验组）

实验组的方案里，**没有一条走进已知死路**：

| 坑 | 规避方式 |
|---|---|
| e1 `body.threadId` 被忽略 | 只用 `POST /v3/conversations` 的 conversationId |
| e2 取最后一条 assistant 会拿到旧终稿 | 条数水位线 `readTurn(rows, afterCount)` |
| e3 UI 进度气泡混进正文 | 按 `messageType === 'text'` 双重过滤 |
| e4-e6 工具透传/改名/invocation 不可行 | webhook 全在插件进程内，只走文本协议 |
| e10-e15 发布/文档/图标/缓存 | 逐条规避 |

### 2. 但棋谱的抽取会漏 —— 原始记忆必须保留

对照组**只拿原始文档**，却补出了 2 条棋谱没收录的坑。

**这不是对照组更强，而是证明：任何「抽取」都会丢信息。** 棋谱是索引，不是真相。

### 3. 所以三层结构是正确性保证，不是可选项

| 层 | 作用 | 实验证据 |
|---|---|---|
| **L1 索引** | 让模型看到**全部**死路 | 实验组 15/15，对照组只看 5 条 |
| **L2 节点** | 每条死路的详情 | 实验组的规避方案每条都具体 |
| **L3 原始** | **补漏** —— 抽取漏了能从这找回来 | 对照组补了 2 条 |

**如果砍掉 L3，那 2 条坑就永久丢了。**

### 4. 「LLM 会不会每层都去读」—— 本次没有

实验组只说读了 index + 15 个相关节点，**没有读任何无关路径**。对照组只读了 2 个文档。

**但**：本次任务**强制要求引用棋谱编号**，可能诱导了多读。真实场景（不强制）下模型会不会自觉读，**还需一个实验**。

## 对插件的启示

1. **保持三层**（index / nodes / raw），不要为了省 token 砍掉 raw
2. **抽取要尽量全**：插件里是规则抽取，也会漏（比如「命令输出里含 `Error` 但 exit 0」这类边界）
3. **L1 必须带一句话原因**：实验组能避开，靠的就是 index 里那 15 行「→ ✗ 一句话原因」
4. **别指望模型自觉读**：真实场景要测
