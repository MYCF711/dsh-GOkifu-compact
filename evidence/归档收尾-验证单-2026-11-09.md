## 4. 关键结论与限制（读结果前必看）

1. **KU-01 失败形态**：compact 臂把同一行的 `status=settled` 当成答案（金标准是 `current=later-ok`），3/3 样本一致。这是「状态词冒充值」的**真实 reader 证据**，也是决策档从 POSITIVE 降为 BOUNDARY 的直接原因。**优先项：渲染消歧**（status 改非值形式 / 单独成行），改完必须重跑离线覆盖并**新预注册**（会改 compact 字节与冻结哈希）。
2. **内容差不可归因给语法**：v1→v3 同时改变语法与内容 —— 18 题/19 行证据行不再逐字出现（pilot 内仅 IE-01 的 `seq=101`）、fold 语境 50→9、ABS 10 题与比较 2 题改原文投影、compact 字符 3882→4267（+9.92%）。要单独识别「关系行」效果需第三臂「v1 语法 + 只补关系字段」，**本轮未做**。
3. **6 条位置推导**（MR-03@224 / MR-07@264 / MR-09@282 / TR-06@454 / TR-07@474 / MR-04@234）标 `REQUIRES_CAPTAIN_APPROVAL`；pilot 选样 **0/6** 命中，扩到 50 题前必须显式授权或分层报告。
4. **raw 政策**：逐样本原始输出只在私有 `tmp/`；公开聚合不含 raw / samples / trace / 推理文本（`"raw"` 字段 0 处）。
5. **决策档更正是 append-only 的**：`decisionBandCorrection` 记录了 `from=EXPLORATORY_POSITIVE, to=BOUNDARY, fromCommit=2c89232`，不要在文档里抹掉旧值。
